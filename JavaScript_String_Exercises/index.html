Three String Exercises

Enter a word or phrase in each task, then click its button to see the result. The programs ignore letter case and check that an input has been provided.

Task 01

Count the letter L

Find the number of uppercase or lowercase L characters in your text.

Result Your result will appear here.

Example: Hello World! → 3 L characters.

Task 02

Count vowels

Count vowels a, e, i, o, u, y, å, ä and ö, regardless of uppercase or lowercase.

Result Your result will appear here.

Example: Hello World! → 3 vowels.

Task 03

Palindrome checker

Check whether a word or phrase reads the same forwards and backwards. Capital letters, spaces and punctuation are ignored.

Result Your result will appear here.

Examples: Madam → palindrome. Padam → NOT palindrome.
