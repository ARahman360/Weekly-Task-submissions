CSS Flexbox Layout

This page demonstrates a responsive menu and content layout using CSS Flexbox.

How the content is laid out

The cards below are direct children of a Flexbox container. The property display: flex; makes the container a Flexbox. The cards are placed next to each other when there is enough screen space.

Flex Container

The parent element uses display: flex. Its direct child elements automatically become flex items.

Flexible Items

flex: 1 1 280px lets the cards grow, shrink and use about 280 pixels as their preferred starting width.

Responsive Design

flex-wrap: wrap allows items to move to another row when the browser becomes too narrow.

Important Flexbox settings

  • display: flex – activates Flexbox for the container.
  • flex-direction – controls whether items are arranged in a row or column.
  • flex-wrap: wrap – allows items to move onto new lines.
  • justify-content – controls horizontal distribution of items.
  • align-items – controls alignment on the cross axis.
  • gap – creates space between flex items.
  • flex – controls how individual items grow and shrink.

How the layout responds to screen size

On a large screen the cards are displayed side by side. If the available space becomes smaller, the cards wrap automatically. A media query is also used at 600 pixels. On small screens the navigation changes into a vertical menu and the cards are displayed in one column.

Features used on this page

  • Responsive Flexbox navigation menu.
  • Hover effect for navigation links.
  • Active menu item highlighting.
  • Flexbox card layout with text and images.
  • Flexible card sizes using the flex property.
  • Automatic wrapping with flex-wrap.
  • Spacing with the gap property.
  • Responsive mobile layout using a CSS media query.
