How the program works

1. Check the date Validate month 1–12, exact days per month, leap years and century marker.
2. Check the number Individual number 002–899; even means female and odd means male in this format.
3. Calculate the character Combine DDMMYY and NNN, divide by 31 and look up the remainder in 0123456789ABCDEFHJKLMNPRSTUVWXY.

Educational demonstration only. A mathematically valid identity code is not proof it has been issued to a real person. Avoid using actual personal identity codes when testing. Validator recognises the additional Finnish century markers introduced from 2023; the generator uses +, - and A as requested in the assignment. Sources: DVV, Statistics Finland.
